Weather App

This is a modern, responsive weather application I built using HTML, CSS, and plain JavaScript. It shows you the current weather and a short-term forecast for any city you search for.

The app gets its data from the OpenWeatherMap API and is designed to work well on both computers and mobile phones.

Features
Current Weather: See the current temperature, location, humidity, and wind speed.

4-Day Forecast: Get a quick look at the weather for the next few days.

Temperature Switch: Easily change between Celsius (°C) and Fahrenheit (°F).

Clean Design: The app has a clean, simple look with smooth animations.

Error Messages: It will tell you if a city can't be found or if there's a problem getting the weather data.

How to Use
Clone this project:

git clone https://github.com/priyam-343/Weather_app.git

Get an API Key:

Sign up for a free account at OpenWeatherMap.

Find your API key in your account dashboard.

Add Your API Key:

Open the script.js file.

Change the API constant to your new key.

Keep in mind it can take a few minutes for a new key to start working.

Open the App:

Just open the index.html file in your web browser to start using the app.
